# f5e version 1.1 (Vite + React skeleton)

## What this is
A minimal Vite + React project skeleton (JavaScript) with a basic Login component so you can start building your AI Resume Analyzer app fast.

## How to run (in VS Code or terminal)
1. Make sure you have Node.js (LTS) installed. Recommended: use `nvm` / `nvm-windows` to install a recent LTS.
2. Open the project folder (`f5e version 1.1`) in VS Code.
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the dev server:
   ```bash
   npm run dev
   ```
5. Open the URL printed by Vite (usually http://localhost:5173).

## What’s included
- `index.html`
- `package.json` (react, react-dom, vite)
- `src/` with a simple `App.jsx` and `components/Login.jsx` + `Login.css`
- `.gitignore` and this `README.md`
